Overview

This repository hosts Singapore Playgrounds & Community Centres, an interactive mapping tool and inventory featuring over 2,200 geocoded locations across Singapore. It combines categorized playground data with the People's Association community centre network, complete with regional filters and verified national map coordinates.
Key Features

    Extensive Inventory: Over 2,200 verified pins covering categorized playgrounds (Groups A-C) and community centres (Group D).

    Regional Filtering: Filter locations quickly by major regions across Singapore (Central, East, North, North-East, and West).

    Geocoded Accuracy: All coordinates are verified to lie within Singapore territory using SLA national map polygons.

    Curated Data Sources: Built using official open data from NParks via data.gov.sg, the People's Association, OpenStreetMap, and curated reference lists.

Data Structure

    Groups A–C: Categorized playground inventories, destination playgrounds, and islandwide aggregate zones.

    Group D: The People's Association community-centre network, PAssion WaVe outlets, and co-located outposts.
